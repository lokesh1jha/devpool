Product Name

Tagline

Purpose

A lightweight Applicant Tracking System (ATS) that allows companies to

• Post jobs

• Review resumes
• Track hiring stages

• Send emails
• Generate offer letters

Initially only one company (internal usage).

----------------------------------------------------
DELIVERABLES
----------------------------------------------------

Build the application incrementally.

Before writing code:

1. Analyze requirements.
2. Design the folder structure.
3. Design the database.
4. Design APIs.
5. Design UI.
6. Explain architecture decisions.

Then implement feature by feature.

Do NOT generate hundreds of files at once.

Each feature should be production-ready before moving to the next.

Always keep the project compiling after every step.

Do not leave TODOs unless explicitly requested.

Whenever there is a design decision, choose the option that would scale to 100,000 candidates and thousands of jobs without requiring major architectural changes.

Think like the founding engineer of a successful SaaS product, not like someone building a tutorial project.
